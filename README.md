# blazor-viacep-net

Aplicação em Blazor WebAssembly (.NET 10) que consulta um CEP na API do ViaCEP
(https://viacep.com.br/ws/{cep}/json/) e mostra o endereço correspondente.

## Como rodar

```
cd BlazorViaCep
dotnet run
```

Depois abra http://localhost:5172, digite um CEP (ex.: 30140-010) e clique em Consultar.
